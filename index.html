GOOD TO KNOW

Before you install.

Is ZX9 ready for public release?

Not yet. ZX9 is still being built and tested. The download button will activate after a public release is published with a tested Windows package.

Will ZX9 automatically change my PC?

No. You choose which supported tweaks to apply. Read each option before using it, and create a restore point before changing Windows settings.

How do I check for updates?

This page checks the configured public GitHub repository for its latest release and displays its version, date, notes, and package link.

Where does ZX9 save my app data?

The current app stores its settings, profiles, activity history, tweak backups, and wallpaper preferences locally in your Windows user profile under %LOCALAPPDATA%\\ZX9. See the privacy notice.
