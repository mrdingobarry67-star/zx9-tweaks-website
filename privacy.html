PRIVACY

Privacy notice

Last reviewed: October 2026. This notice describes the current ZX9 website and app; review it again whenever data practices change.

Website

This static website does not currently use analytics, advertising trackers, or cookies. To display release information, it requests public release metadata from the configured GitHub repository. GitHub may receive standard connection information when your browser contacts its services.

ZX9 desktop app

The current app saves preferences, profiles, activity history, tweak backups, and wallpaper settings locally under %LOCALAPPDATA%\\ZX9. The current code does not include an app analytics or telemetry upload feature. The optional Spotify wallpaper integration reads playback information from Windows media controls on your PC.

Windows settings and permissions

Some app tools inspect system information or change Windows settings when you choose to apply a supported tweak. Review the description of each action, make a restore point before changing system settings, and keep Windows security protections enabled.

Questions and changes

For privacy questions, use the project contact or support link listed on the ZX9 website. This notice should be updated if ZX9 adds online accounts, diagnostics uploads, analytics, or other data collection.
